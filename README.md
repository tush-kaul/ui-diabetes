## Terminal Commands

1. Install "tailwindcss_v3", "postcss", "autoprefixer"
```bash
pnpm add -D tailwindcss@^3 postcss autoprefixer
```
2. Install "tailwindcss-animate"
```bash
pnpm add -D tailwindcss-animate
```
3. Set node environment to "Development"
```bash
NODE_ENV=development
```
4. Clear Next.js cache
```bash
rm -rf .next
```
5. Clear pnpm cache (optional but thorough)
```bash
pnpm store prune
```
6. Restart with fresh cache
```bash
pnpm dev
```
